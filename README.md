# Домашнє завдання. Блокчейн, частина 2 (Proof of Work)

## ✅ Рівень 1. Обов'язкова частина

1. Інтегрувати механізм Proof of Work у ваш проєкт. Створити клас MiningService.
2. Додати поле Nonce до класу Block.
3. Оновити метод обчислення хешу в HashingService, щоб він обов'язково враховував поле Nonce.
4. Змайнити 3 нові блоки зі складністю (Difficulty)
5. Вивести ланцюг у консоль і переконатися, що перевірка IsValid працює коректно.

## ✅ Рівень 2. Аналіз продуктивності

1. Написати логіку, яка генерує по одному тестовому блоку для кожного рівня складності: 1, 2, 3, 4 та 5.
2. За допомогою класу Stopwatch заміряти час, витрачений на майнінг кожного з цих блоків.
3. Вивести результати в консоль у вигляді таблиці з колонками: Складність | Кількість спроб (Nonce) | Витрачений час.

## Рівень 3. Складне завдання (Симуляція злому мережі)

1. Створіть ланцюг із 5 блоків зі складністю 3 або 4.
2. Напишіть метод HackChain, який приймає індекс блоку та нові підроблені дані.
3. Цей метод повинен змінити дані у вказаному блоці та запустити для нього процес майнінгу (підбору нового Nonce).
4. Після цього метод повинен циклом пройтися по всіх наступних блоках до самого кінця ланцюга, оновити їхній PrevHash на новий і наново змайнити кожен із них.
5. Заміряйте і виведіть у консоль загальний час, який знадобився комп'ютеру для повного перерахунку та "злому" ланцюга.

### Що завантажити на перевірку:

1. Скріншоти консолі з результатами роботи програми (має бути видно таблицю аналізу продуктивності та час злому ланцюга).
2. Посилання на ваш репозиторій у Git (GitHub/GitLab) з оновленим кодом проєкту.
